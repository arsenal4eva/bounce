# bounce
## This is a game made during Hackclub Haven
 Place trampolines at the start of every stage and then play!
 Start screen (titlescreen.tscn) -> user clicks start or exit -> if exit, exit, if start, go to the rules page(rules.tscn) -> user can choose either to play tutorial or start playing straightaway. -> if tutorial, go to level_0.tscn, there should be text boxes that appear sequentially to explain how to play and run the user through a demo. if play straightaway, go to level_1.tscn and start level 1. at the end of each level, go to betweenlevels.tscn. it will show the level number, and give three options, continue to next level, replay previous level or exit game. the level number should depend on Global.currlevel which should be updated accordingly everytime the scene betweenlevels.tscn is reached. The final level is level 10. Once the user completes level 10 successfully, the win screen should be displayed. the win screen is just some text that says good job you won. If the user chooses to quit in the middle, it should display a screen with text saying thanks for playing.
# Gameplay:
 In each level, the user starts on a block(block.tscn) in the map. There are a set number of trampolines(jump_pad.tscn) that a user can place across the map. The trampolines are required to allow the user to be able to reach the end successfully when placed strategically. At the start of each level, the camera is in view mode, which displays the whole map of that level including all its obstacles, blocks, spikes(spikes.tscn). A number of trampolines is then displayed on the bottom of the map in a row, and the user can click on a trampoline, drag it to its new position, then rotate it. Once all trampolines are placed, the user clicks a button called “Play level” which locks the trampolines in place and the camera goes into play mode. in play mode, the user is not allowed to change the positions of trampolines. the camera will focus with the player in the center, and move with the player, showing a limited radius. the player can move left and right using left /right arrow keys and jump up using spacebar. If the user hits the spikes, or falls out of the scene itself, the user respawns. the respawn points are in Global.checkpoints in a list of the coordinates. for now, it is just level0 and level1. the checkpoint for level x is in Global.checkpoints[x] . To complete a level, the user must use the trampolines and left/right arrows to get to cross the line(door.png) on the right side of the map. Once the user touches it, it counts as level completion and goes to betweenlevels.tscn. When the user respawns, give the user the option to continue play mode, or go back to view mode and change the positions and orientations of trampolines then go back to play mode.
# Level design:
 Blocks are placed using tile map layer for godot. spikes(spike.tscn) currently has its spikes facing left. the spikes should be facing away from the part in contact with the block that it is placed on, or towards the player.
 For level 1-3, the trampolines are all placed by the player.
 For level 4-6, there will be pre placed trampolines that rotate around its center forever and the player is launched in the direction the trampoline is pointing upon contact. the player is still able to place their own trampolines. There will be moving spike walls for level 6 that move in a set direction and reverse motion upon collision with object or frame of map.
 For level 6-9, there will be moving trampolines. moving trampoline mechanic: the trampoline will start moving towards a set direction once the player bounces on it, the trampoline will destroy itself once it hits a solid object, the trampoline only points upward.
For level 10, everything is combined into one large map.
